# Wraith
A platformer game where you control a knight

# Description
this project is a game where you control a knight and he goes through 2 levels of light and darkness avoiding enemies on the way to reach the end portal this project was made entirely in godot created this project for operation blackout and to also further my knowledge on Godot and how to create a working enemy
